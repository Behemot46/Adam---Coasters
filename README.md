# תג אחד על השולחן

תגי NFC ממותגים, מודפסים בתלת מימד, לבתי קפה ומסעדות עצמאיים.

## מה יש כאן

- `business-plan/tag-on-the-table-v2.html` – גרסה 2 של התוכנית העסקית: שוק, מתחרים, ערך בלעדי, תמחור לפי שולחנות, ייצור מול צד ג׳, כשל ובלאי, נקודות איזון ושערי החלטה ל-60 יום. [גרסה מקוונת](https://claude.ai/artifact/QLxYwn8BjH9NkGtgseSSrx)
- `business-plan/letter-to-adam.html` / `.md` – מכתב התייחסות לתוכנית. [גרסה מקוונת](https://claude.ai/artifact/MsQDxMd5ifQtxXFZGzHdv2)
- `business-plan/model/` – מודלי Python שמאחורי הטבלאות והמחשבונים (`python3 final.py`, `python3 tornado.py`, `python3 owner_value.py`).
- `site/karov-landing.html` – דף הנחיתה של "קרוב" לבעלי בתי קפה: הדמיה חיה מהשולחן ללוח ליד הבר, ביקור אחד בשולחן 7, הסטנד, סיכום חודשי לדוגמה, ומחיר חודשי אחד לפי התחייבות ל-3, 6 או 12 חודשים. [גרסה מקוונת](https://claude.ai/artifact/818bf8bd-f939-48ec-a1ea-3d4e1b1e4f3d)
- `site/karov-focus.html` – גרסה ממוקדת של דף הנחיתה: מוכרת רק את "משהו לא בסדר" שמגיע לאחראי המשמרת, עם אותם מחירים לפי התחייבות. [גרסה מקוונת](https://claude.ai/artifact/1HTZ7oaGM3bvzuPqRg7R9C)
- `site/karov-live.html` – הדגמה חיה מול בסיס נתונים משותף: דף שולחן ללקוח (`#t7` לצ׳יפ NFC, `#q7` לקוד QR), לוח צוות, דוח לבעלים והגדרות. רק בעלי הדף ומי שהוזמן כעורך יכולים לשלוח ולעדכן. [גרסה מקוונת](https://claude.ai/artifact/RvmjBDBjpxq152qEX1nuqU)
